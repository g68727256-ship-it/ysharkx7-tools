Central Minecraft Bedrock

Guias para criar e instalar packs no Minecraft Bedrock Edition.

Os caminhos e recursos mudam entre plataformas (Android, Windows, consoles) e versões. Teste no seu aparelho e consulte a documentação oficial da Microsoft para criadores.

Estrutura de pastas de um resource pack
MeuPack/
├─ manifest.json
├─ pack_icon.png
├─ textures/
│  ├─ blocks/
│  ├─ items/
│  ├─ entity/
│  └─ ui/
└─ texts/ (opcional)

O manifest.json fica na raiz da pasta. Para um behavior pack a estrutura é outra (entities, scripts etc.).

Criar o manifest.json

Use o Gerador de Manifest: ele cria os UUIDs e o JSON. Cada pack precisa de UUIDs próprios.

Instalar um resource pack
  1. Compacte o conteúdo da pasta (manifest na raiz do zip) e renomeie para .mcpack, ou copie a pasta para development_resource_packs dentro de com.mojang.
  2. Abra o arquivo .mcpack com o Minecraft, quando a plataforma permitir, para importar.
  3. Ative em Configurações > Recursos globais (ou no mundo, em Recursos).

Em alguns Androids recentes o acesso à pasta com.mojang é restrito pelo sistema. Se não conseguir, use a importação por .mcpack.

Texturas e interfaces
  • Texturas são PNG. Mantenha resolução em potência de 2 (16x, 32x, 64x...).
  • Texturas de blocos novas ou trocadas precisam ser listadas em textures/terrain_texture.json, e as de itens em item_texture.json.
  • Interfaces usam arquivos JSON na pasta ui. Erros nesses arquivos podem quebrar telas: trabalhe com cópia de segurança.
Converter texturas Java para Bedrock

Não há conversão automática garantida. O que costuma ser necessário:

  • Renomear pastas: Java usa textures/block e textures/item; Bedrock usa textures/blocks e textures/items.
  • Alguns arquivos têm nomes diferentes entre as edições, e precisam ser renomeados um a um.
  • Criar o manifest.json (Java usa pack.mcmeta) e registrar as texturas nos arquivos JSON de lista.
  • Interface, sons e modelos não são compatíveis diretamente.
