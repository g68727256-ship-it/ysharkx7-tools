Central Minecraft Java

Guias práticos para Minecraft Java Edition: mods, resource packs, versões e Android.

Informações gerais. Versões, nomes de menus e launchers mudam com o tempo: confira sempre a fonte oficial do mod, do launcher ou a Minecraft Wiki.

Como instalar mods
  1. Descubra a versão do jogo (ex.: 1.20.1) e escolha o loader do mod: Fabric, Forge ou NeoForge. O mod só funciona com o loader e a versão para os quais foi feito.
  2. Instale o loader pelo instalador oficial dele e abra o jogo uma vez com esse perfil.
  3. Baixe o mod de uma fonte confiável (como Modrinth ou CurseForge) e confira a versão e o loader na página.
  4. Coloque o arquivo .jar na pasta mods dentro da pasta do jogo (.minecraft). Crie a pasta se não existir.
  5. Abra o launcher com o perfil do loader. Se o jogo fechar ao abrir, remova o último mod e confira dependências (alguns mods exigem outro mod, como Fabric API).
Resource packs no Java

Um resource pack é uma pasta ou .zip com pack.mcmeta e as texturas em assets/minecraft/textures. Coloque em .minecraft/resourcepacks e ative em Opções > Pacotes de recursos.

O campo pack_format do pack.mcmeta muda conforme a versão do jogo. Consulte o valor da sua versão na Minecraft Wiki. Se estiver errado, o jogo avisa que o pack é incompatível, mas costuma permitir ativá-lo.

Compatibilidade de versões
  • Mods: versão do jogo e loader precisam bater. Atualizar o jogo quebra mods antigos até o autor lançar uma versão nova.
  • Resource packs: costumam funcionar entre versões próximas, mas texturas novas podem faltar.
  • Mundos criados em versão nova geralmente não abrem em versão mais antiga. Faça backup antes de atualizar.
  • Não existe regra única: a página de cada mod ou pack informa o que o autor testou.
Minecraft Java no Android

O Java Edition não tem versão oficial para Android. Existem launchers de terceiros não oficiais, e o desempenho e a estabilidade variam por aparelho e versão. Eles não são da Mojang nem deste site: baixe só de páginas oficiais dos projetos, leia as instruções e use uma cópia legítima do jogo.

  • Prefira versões leves do jogo e poucas ou nenhuma modificação.
  • Use distância de renderização baixa (veja o Guia de FPS).
  • Feche outros apps e mantenha armazenamento livre.
